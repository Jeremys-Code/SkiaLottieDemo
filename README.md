I built a C# demo for using multiple Lottie animations on the same page of a .NET MAUI app. There are two dropdown lists that let you select from the Meteocon library of Lottie's. The solution was created and built in Visual Studio 2026. The Nuget packages are up to date as of October 6th 2026. I hope someone else might find this app helpful if they ever need to implement Lottie's in their .NET MAUI app. Thank you.
